# 원고 탐색창

작품 창에서 액티비티 바의 책 아이콘 **Manuscript**를 열면 **Navigator**에 부, 장, 문서가 표시된다. 새 작품 창은 Navigator부터 연다. 마지막으로 사용한 사이드바, 현재 폴더, 펼쳐 둔 폴더와 선택은 작품마다 기억한다.

## 원고 구조 만들기

- Navigator 제목의 **New Part**, **New Chapter**, **New Document**로 항목을 만든다. 선택한 폴더가 그 종류를 담을 수 있으면 그 안에 만든다. 그 외에는 현재 폴더에서 시작해 해당 종류를 담을 수 있는 상위 폴더에 만든다.
- 부와 장의 번호는 같은 폴더 안에서 같은 종류를 1부터 센다. 장 번호는 부마다 1부터 시작한다.
- 항목을 한 번 클릭하면 선택한다. 폴더를 더블클릭하거나 선택한 상태에서 Enter를 누르면 해당 폴더 안으로 들어간다. 맨 위의 `..`를 누르거나 Backspace를 누르면 상위 폴더로 돌아간다.
- 폴더의 ▸ 버튼 또는 오른쪽 방향키로 하위 항목을 제자리에서 펼친다. 왼쪽 방향키로 접고, **Collapse All**로 모두 접는다.
- F2 또는 **Rename...**으로 제목을 편집한다. Enter로 저장하고 Escape로 취소한다. **Delete**를 누르면 항목을 삭제할지 확인한다. 폴더를 삭제하면 하위 항목도 삭제된다.

## 순서 바꾸기

- 행 위나 아래에 끌어 놓아 그 행의 앞뒤로 옮긴다. 펼친 폴더의 행 아래쪽에 놓으면 표시선이 가리키는 폴더 안 첫 자리에 넣는다. 접힌 폴더 가운데에 머물면 폴더가 펼쳐진다. 끌어온 항목을 담을 수 있는 폴더의 가운데에 놓으면 그 폴더 안의 끝으로 옮긴다.
- `..` 위에 놓으면 상위 폴더의 끝으로, 목록 빈 곳에 놓으면 현재 폴더의 끝으로 옮긴다.
- Ctrl(맥에서는 Command)을 누른 채 클릭하여 여러 항목을 고른 뒤 함께 옮길 수 있다. 한 항목은 Alt+위 또는 Alt+아래로 같은 폴더에서 한 칸 옮긴다.

## 문서 열기

- 문서 행을 더블클릭하거나 문서를 선택한 뒤 Enter를 누른다. 이미 열린 문서는 해당 탭을 활성화한다.
- 폴더의 컨텍스트 메뉴에서 **Open All Documents**를 선택하면 하위 문서를 트리 순서대로 최대 50개까지 연다. 첫 문서가 활성 탭이 된다.
- 탭에는 문서 제목이 표시되고, 탭에 포인터를 올리면 부·장 경로도 함께 표시된다.

## 에디터 영역에 끌어 놓기

- 문서나 폴더를 에디터 그룹 가운데에 놓으면 그 그룹에서 연다. 가장자리에 놓으면 그 방향으로 만든 새 그룹에서 연다.
- 폴더를 놓으면 **Open All Documents**와 같이 트리 순서대로 최대 50개까지 열린다.

## Properties에서 제목 고치기

- Navigator에서 항목 하나를 고르면 **Properties**에 제목, 종류, 표시 라벨, 생성·수정 시각이 보인다. 폴더에는 바로 아래의 항목 수도 표시된다.
- **Title**에 제목을 입력한 뒤 Enter를 누르거나 입력란에서 초점을 옮기면 저장된다. Escape로 입력을 되돌린다. Navigator에서 다른 항목을 선택하면 편집 중이던 제목을 버린다.

## 다른 창의 변경 가져오기

다른 창에서 바꾼 구조는 **Refresh**를 누르면 보인다. 오래된 트리로 변경을 시도하면 저장 충돌을 알리고 현재 구조를 다시 불러온다. 제목을 편집 중이었다면 입력한 내용을 확인한 뒤 Enter로 다시 저장할 수 있다.
