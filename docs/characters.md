# 등장인물 탐색창

작품 창에서 액티비티 바의 사람 아이콘 **Characters**를 열면 **Navigator**에 인물과 폴더가 표시된다. 폴더를 여러 단계로 만들어 인물을 묶을 수 있다. 탐색창은 작품마다 현재 폴더, 펼쳐 둔 폴더, 선택한 항목을 기억한다.

## 탐색창 열기와 구조 만들기

- 목록이 비어 있으면 **New Character** 또는 **New Folder**로 첫 항목을 만든다. 이름을 입력하고 Enter로 저장하거나 Escape로 이름 편집을 끝낸다. 인물 아이콘은 남성, 여성, 미정, 동물 유형을 표시한다.
- 한 번 클릭하면 항목을 선택한다. Ctrl(맥에서는 Command)을 누른 채 클릭하거나, 그 키를 누른 채 위·아래 방향키로 이동한 뒤 Space를 눌러 선택에 항목을 더하거나 뺀다.
- 폴더를 더블클릭하거나 해당 행에서 Enter를 누르면 폴더 안으로 들어간다. `..`나 Backspace로 상위 폴더에 돌아간다.
- 폴더의 ▸ 버튼이나 오른쪽 방향키로 하위 항목을 펼친다. 같은 행에서 왼쪽 방향키로 접는다.
- F2를 누르면 선택한 행의 이름을 편집한다. Delete를 누르면 삭제 여부를 확인한다.

## 필드 템플릿 열기와 저장

- 작품 창에서 **Characters: Edit Field Template**을 실행하거나 **Navigator** 제목의 톱니바퀴 버튼을 누른다. 이미 열려 있는 **Field Template** 탭은 앞으로 가져온다. 처음 여는 작품에는 기본 필드 여덟 개가 표시된다.
- 편집한 템플릿은 Ctrl+S(맥에서는 Command+S)로 저장한다. 변경을 남긴 채 마지막 탭을 닫으면 저장, 버리기, 취소 중 하나를 고를 수 있다.
- 먼저 저장된 변경이 있으면 알림이 뜨고 저장된 버전을 다시 읽는다. **Discard Draft and Reload**로 저장된 버전을 쓰거나 **Overwrite Saved Template**으로 초안을 저장한다. 그사이 누군가 다시 저장했다면 선택을 다시 묻는다.
- 새로고침하면 탭이 저장된 템플릿을 다시 연다. 저장하지 않은 편집은 사라진다.

## 순서 바꾸기

- 행 위나 아래에 끌어 놓으면 앞뒤로 옮긴다. 펼친 폴더 행의 아래쪽에 놓으면 표시선이 가리키는 첫 자리에 들어간다. 폴더 가운데에 놓으면 그 폴더의 끝으로 옮긴다. 접힌 폴더 가운데에 잠시 머물면 폴더가 펼쳐진다.
- 여러 항목을 선택한 뒤 함께 끌면 기존 트리 순서를 유지한다. 폴더를 옮기면 하위 항목도 따라간다.
- `..` 위에 놓으면 상위 폴더의 끝으로, 목록 빈 곳에 놓으면 현재 폴더의 끝으로 옮긴다.
- 한 항목을 Alt+위 또는 Alt+아래로 같은 폴더에서 한 칸 옮긴다. 컨텍스트 메뉴의 **Move Up**, **Move Down**도 같은 동작을 한다.

## 메뉴와 커맨드

- Navigator 제목의 **New Character**와 **New Folder**로 항목을 만든다. 선택한 폴더가 있으면 그 안에, 아니면 현재 폴더에 만든다. 새 인물은 미정 유형으로 시작한다.
- **Refresh**로 다른 창에서 저장한 내용을 불러오고, **Collapse All**로 펼친 폴더를 모두 접는다.
- 행의 컨텍스트 메뉴에서 **Enter Folder**, **Rename...**, **Set Type**, **Delete**를 쓴다. 폴더를 지울 때는 안에 든 모든 인물 수를 확인할 수 있다.
- 여러 항목을 선택하고 **Set Type**에서 유형을 고르면 선택한 모든 인물의 유형이 바뀐다. 선택한 인물의 유형이 모두 같으면 메뉴에 체크가 표시된다. 도중에 저장 충돌이 나면 현재 트리를 다시 읽고 알린다. 이미 저장한 변경은 반영된다.
- 작품 창의 커맨드 팔레트에서 `Characters:`로 찾으면 탐색창 커맨드가 나온다.
