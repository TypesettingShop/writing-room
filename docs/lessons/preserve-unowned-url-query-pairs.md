# 쿼리에서 관리하는 매개변수만 편집한다

## What happened

- 잘못된 작품 링크에서 `work`를 제거하면서 다른 쿼리 쌍의 공백 인코딩, 슬래시와 값 없는 플래그의 철자가 바뀌었다.

## Why

- `URL.searchParams`를 변경하면 브라우저가 전체 쿼리를 폼 인코딩으로 다시 직렬화한다. 매개변수를 읽을 때 같은 값이어도 원문 URL은 달라질 수 있다.

## Do this instead

- 원문 보존이 필요한 URL에서는 이름만 해석해 변경할 쌍을 찾는다. 다른 쌍의 원문과 순서를 유지한다.
- 회귀 테스트에서 삭제할 이름의 인코딩된 형태와 남겨야 할 이름의 경계를 확인한다. 남은 쌍은 해석한 값과 함께 주소의 원문도 확인한다.
