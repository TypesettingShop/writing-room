# 확장 정리는 메인의 remove와 호스트의 release를 따로 테스트한다

## What happened

- 창 UI 에픽에서 확장을 제거하면 채널과 진행 표시가 사라지는지 보는 테스트가 메인 쪽 `remove`만으로 통과했다. 확장 호스트의 `release`를 비워도, 취소 가능한 작업만 토큰을 취소해도 빨개지지 않았다 (wr-x0vf.ng4 발견 15, 17).

## Why

- 정리는 두 스레드에서 따로 일어난다. 메인은 화면에서 지우고, 호스트는 모인 쓰기, 토큰, 이벤트 같은 자기 쪽 상태를 버린다. 화면만 보는 단언은 호스트 쪽 정리를 증명하지 못한다.

## Do this instead

- 메인의 `remove`와 호스트의 `release`를 각각 부르는 테스트를 둔다. 호스트 쪽 테스트는 해제 뒤에 RPC가 더 나가지 않는지, 토큰이 취소되는지, 다른 확장의 것은 남는지를 본다.
- 정리 함수를 비우거나 조건을 좁혀 테스트가 실패하는지 한 번 확인한다.

Learned in: wr-x0vf.ng4
