# 모델을 가진 입력은 리소스마다 하나만 만든다

## What happened

- 에디터 해석기의 제목 없는 문서 팩토리가 리소스로 열 때마다 `new UntitledTextEditorInput(model)`을 만들었다.
- 같은 문서가 이미 다른 그룹에 열려 있으면 한 모델 위에 입력이 둘 생겼고, 입력은 dispose될 때 모델도 지우므로 한쪽 탭을 닫자 다른 탭의 텍스트가 사라졌다 (wr-h23m.sxv #1).

## Why

- 그룹은 `matches`로 같은 탭을 찾지만, 서로 다른 그룹은 서로 다른 입력 객체를 들 수 있다. "마지막 그룹이 놓으면 입력을 지운다"는 규칙은 입력 객체 단위로 세므로, 같은 모델의 두 번째 입력은 첫 번째의 탭 수를 모른다.

## Do this instead

- 입력이 모델(또는 다른 자원)의 주인이면, 리소스로 입력을 만드는 곳(해석기 팩토리, 직렬 변환기, 커맨드)은 먼저 열린 그룹들에서 같은 리소스의 입력을 찾아 그것을 돌려준다. 없을 때만 새로 만든다.
- 테스트: 같은 리소스를 두 그룹에서 열고 한쪽을 닫은 뒤 다른 쪽의 텍스트와 모델이 살아 있는지 본다.
