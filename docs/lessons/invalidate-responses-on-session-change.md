# 계정 세션이 바뀌면 앞선 세션의 응답을 무효화한다

## What happened

- 작품 창이 로그인된 세션을 이웃 탭에서 새로 받았다. 새 세션의 Works 읽기는 성공했지만, 먼저 보낸 요청의 401이 나중에 도착해 로그인 폼과 세션 상실 알림이 나왔다.

## Why

- 응답이 도착하는 순서는 요청을 보낸 순서와 다를 수 있다. 로그아웃 시점에만 요청 세대를 높이면 다른 탭에서 로그인을 확인한 뒤에도 앞선 요청이 같은 세대를 갖는다.

## Do this instead

- 보호된 요청을 보낼 때 현재 세션 세대를 함께 기억한다. 로그아웃과 재로그인이 확인되면 세대를 높이고, 이전 세대의 응답으로 현재 계정 상태를 갱신하지 않는다.
- 실제 세션 상태를 알리지 않는 서버 장애와 라우터 오류는 접속 가능 여부만 바꾼다.
- 오래된 200이 로그아웃 뒤 도착하는 경우와 오래된 401이 재로그인 뒤 도착하는 경우를 각각 순서를 제어하는 테스트로 확인한다.
