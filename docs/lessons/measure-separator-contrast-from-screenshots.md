# 구분선의 대비는 인접한 스크린샷 픽셀로 확인한다

## What happened

- 분할 에디터의 구분선은 계산된 CSS 색과 폭이 맞았지만 내장 라이트·다크 테마에서 탭 바와 빗금 여백에 묻혔다. Markdown 본문 양옆에도 같은 색을 써서 세로선 셋 가운데 어느 선이 그룹 경계인지 알아보기 어려웠다.

## Why

- 배경 한 곳의 색과 비교하면 같은 선이 지나가는 탭 바나 빗금에서 생기는 낮은 대비를 놓친다. 계산된 가상 요소 스타일은 다른 요소가 선을 가리거나 선이 활성 탭 표시를 덮는 경우도 보여 주지 않는다.

## Do this instead

- 브라우저 스크린샷에서 선의 픽셀과 인접 픽셀을 잰다. 탭 바, 편집기 배경, 빗금 양쪽에서 채취하고 각 영역의 최저 대비를 확인한다.
- 그룹처럼 더 큰 구조를 구분하는 선과 본문 장식선을 각자 다른 테마 색으로 지정한다. 겹치는 활성 표시와 Webview에는 실제로 그려진 경계 픽셀도 검사한다.
