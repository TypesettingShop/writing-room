# 구분선의 대비는 인접한 스크린샷 픽셀로 확인한다

## What happened

- 분할 에디터 구분선의 CSS 색과 폭은 의도한 값으로 계산됐다. 내장 라이트·다크
  테마에서는 구분선이 탭 바와 빗금 여백에 묻혔다. Markdown 본문 양옆에도 같은
  색을 써서 세로선 셋 중 어느 선이 그룹 경계인지 알아보기 어려웠다.

## Why

- 배경 한 곳의 색과 비교하면 구분선이 지나가는 탭 바나 빗금 여백에서 대비가
  낮은 구간을 놓친다. 가상 요소의 계산된 스타일만으로는 다른 요소가 선을
  가리거나 선이 활성 탭 표시를 덮는 경우를 확인할 수 없다.

## Do this instead

- 브라우저 스크린샷에서 선과 그에 인접한 픽셀을 비교한다. 탭 바, 편집기 배경,
  빗금의 양쪽에서 픽셀을 채취하고 각 영역의 최저 대비를 확인한다.
- 그룹처럼 큰 구조를 구분하는 선과 본문 장식선에 서로 다른 테마 색을 지정한다.
  활성 표시가 겹치는 곳과 Webview에서도 실제로 그려진 경계 픽셀을 검사한다.
