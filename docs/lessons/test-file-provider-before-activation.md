# 파일 제공자를 처음 여는 호출로 활성화를 시험한다

## What happened

- 파일 시스템 브라우저 테스트가 `workspace.fs.stat`을 실행한 뒤
  `openTextDocument`를 불렀다. 먼저 실행한 호출이 제공자를 활성화해
  문서 열기의 활성화 누락이 드러나지 않았다.

## Why

- `workspace.fs`와 문서 API는 서로 다른 진입점이다. 제공자가 등록된
  상태에서 문서를 여는 테스트는 문서 진입점이 등록을 기다리는지
  확인할 수 없다.

## Do this instead

- 제공자를 해당 스킴의 `onFileSystem:` 이벤트에서만 등록하는 픽스처를 쓴다.
- 새 페이지에서 해당 스킴이 아직 등록되지 않았음을 확인한다. 검사하려는
  API를 파일 제공자를 쓰는 첫 호출로 두고, 문서 내용과 편집기 표시까지 검사한다.
