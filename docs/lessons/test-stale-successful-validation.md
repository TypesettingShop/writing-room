# 오래된 비동기 응답의 수락 테스트에는 성공 응답을 사용한다

## What happened

- 퀵 인풋 회귀 테스트에서 앞선 입력의 지연 검증이 오류 메시지를 돌려줬다. 입력이 이미 바뀌었는지 확인하는 수락 조건을 지워도 이전 입력은 검증 오류 때문에 수락되지 않아 테스트가 통과했다.

## Why

- 검증이 성공한 경우에만 수락 경로가 실행된다. 오래된 요청의 성공과 실패는 위젯을 닫는 동작에 미치는 영향이 다르다.

## Do this instead

- 유효한 값을 수락하도록 요청한 뒤 검증은 대기시킨다. 입력을 새 값으로 바꾸고 새 검증이 오류를 표시할 때까지 기다린다.
- 이전 요청을 성공으로 확정한 뒤 위젯이 열린 상태이며 새 오류가 표시되는지 확인한다. 이어서 현재 값을 유효한 값으로 수정하고 정상적으로 수락되는지도 확인한다.
