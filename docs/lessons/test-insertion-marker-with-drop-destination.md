# 드롭 표시선과 저장할 위치를 한 경로에서 검증한다

## What happened

- 펼친 폴더 행 아래에 그린 삽입선은 폴더와 첫 자식 사이에 있었다. 실제 드롭은 폴더의 하위 트리 전체 뒤에 삽입했다.

## Why

- 행의 시각적 순서와 드롭 대상의 구조적 형제 순서가 다르다. 두 가지를 따로 시험하면 같은 포인터가 가리키는 위치의 차이를 놓친다.

## Do this instead

- 하나의 포인터 위치에 대해 표시선이 그려진 행과 실제 쓰기 요청의 부모 및 앞에 놓일 자식을 함께 검사한다. 펼친 폴더, 접힌 폴더, 이미 끌고 있는 자식을 예로 든다.
- 첫 `dragenter` 뒤 곧바로 놓는 시험에서는 `dragover`를 보내지 않는다. 같은 트리 안에서도 거절된 행에서 허용된 행으로 들어갈 수 있다.
