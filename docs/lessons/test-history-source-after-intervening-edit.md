# 중간 편집을 포함한 실행 취소·다시 실행에서 원문을 비교한다

## What happened

- 외부 모델 변경으로 제목과 목록의 Markdown 표기가 바뀐 뒤 WYSIWYG에서 글자를 더 입력했다. Undo 두 번과 Redo 한 번을 했더니 제목은 처음 표기로, 목록은 외부 변경의 표기로 섞여 저장됐다. wr-ndsy.0xv 발견 1에서 회귀 테스트를 추가했다.

## Why

- 나중 편집을 되돌리면서 구조가 같은 새 ProseMirror Fragment가 생겼다. 원문 스냅샷을 Fragment 객체로 찾는 경로에서는 새 객체에 원문과 출처를 따로 이어 주어야 했다.

## Do this instead

- 외부에서 원문 표기를 바꾼 뒤 WYSIWYG 편집을 하나 얹고, 각 편집을 역순으로 Undo한 다음 순서대로 Redo한다. 모든 중간 단계에서 공유 텍스트 모델의 문자열을 비교한다.
- 테스트에서 제목 기호나 목록 기호처럼 렌더링만 보면 놓치기 쉬운 표기를 바꾼다. 이력 경로가 새 Fragment를 만들면 실제로 모델에 쓴 원문과 출처를 이후 이력이 찾을 수 있게 저장한다.

Learned in: wr-ndsy.0xv
