# 저장·재개방 회귀는 기존 텍스트 파일 서비스 하네스에서 검사한다

## What happened

- WYSIWYG 편집의 저장·재개방 회귀가 편집기 모델 테스트에서 파일 공급자와 모델 서비스를 다시 구성했다. 파일 서비스 테스트에는 같은 저장 경로를 실행하는 설정이 이미 있었다.

## Why

- 실제 파일 저장에는 파일 바이트, 저장 버전, dirty 상태 및 모델 재개방이 함께 관여한다. 테스트가 각각 설정을 만들면 모델의 대체 버전처럼 저장 결과에 영향이 있는 동작이 한쪽에만 들어가기 쉽다.

## Do this instead

- 저장한 파일과 다시 연 모델을 검증하는 회귀는 `textFileService.test.ts`의 기존 `createService`와 `resolve`를 사용한다. 파일 모델의 dirty 상태, 저장 바이트, 다시 연 편집기의 결과를 같은 시나리오에서 확인한다.
- 편집기 모델 테스트는 원문 이벤트와 대기 트랜잭션의 위치 대응처럼 모델 안에서 판정할 수 있는 동작을 확인한다.
