# 확장 기본 기여는 지역화 읽기 전에 등록한다

## What happened

- wr-mn1x.0xo의 리뷰에서 한국어 로캘로 시작할 때 원격 확장 번역 파일 하나가
  모든 기여 등록과 시작 활성화를 늦추는 것을 발견했다. 지역별 번역과 언어
  대체 번역을 차례로 받는 동안 다른 확장의 명령과 뷰도 나오지 않았다.

## Why

- 설치 때 보관한 매니페스트와 기본 번역은 로컬에서 바로 읽을 수 있다.
  언어별 번역의 읽기 시간과 성공 여부는 서버와 개별 확장에 달려 있다.

## Rule

- 언어별 번역을 요청하기 전에 기본 기여를 등록한다. 추가 읽기에 시간 제한을
  두고, 현재 설치 세대의 번역이 준비되면 표시 문자열을 갱신한다.
- 테스트에서 번역 응답 하나를 보류하거나 실패시킨다. 기본 기여가 등록되고 다른
  확장의 번역이 적용되는지 확인한다. 지역이 붙은 로캘은 일반 영어 기본값과
  지역별 표 선택을 각각 확인한다.

Decided in: wr-mn1x.0xo
