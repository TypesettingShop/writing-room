# 스타일시트의 테마 색은 기본 라이트와 다크에서 값을 확인한다

## What happened

- World 프리셋 버튼 테두리에 기본 테마 값이 비어 있는 색 토큰을 사용해 스타일시트 계약 테스트가 실패했다. 테두리를 두 기본 테마에 값이 있고 고대비에서는 경계가 보이는 contrastBorder로 바꿨다.

## Do this instead

- 스타일시트가 새로운 테마 색 변수를 읽으면 색 레지스트리에서 기본 라이트와 다크의 값도 확인한다. CSS fallback을 넣었더라도 스타일시트 계약 테스트는 두 기본 테마에 값이 있는지 확인한다.
- 색 관련 변경 뒤 themeStylesheets.test.ts를 실행하고, 고대비에서 그 색이 들어간 경계나 글자가 보이는지 확인한다.
