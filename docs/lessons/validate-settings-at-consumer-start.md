# 서버를 띄우는 경로에서 서버 설정을 검증한다

## What happened

- Vite 설정을 읽는 순간 API 프록시 포트를 검사했다. 프록시가 필요 없는 브라우저 번들 빌드와 Vitest도 동일한 설정 파일을 읽어, API 포트가 0이거나 잘못되면 시작하지 못했다.

## Why

- 설정 모듈은 빌드, 테스트, 요청을 받는 프로세스가 공유할 수 있다. 각 프로세스가 실제로 사용하는 값의 범위가 다르다.

## Do this instead

- 공통 설정은 가져와도 서버 변수 검증이 실행되지 않게 구성한다. Vite의 개발·프리뷰 서버처럼 프록시를 여는 경로에서 그 값을 읽고 검증한다.
- 프록시를 사용하는 테스트와 함께, 아직 API 주소가 정해지지 않은 환경에서 빌드와 테스트가 실행되는지 확인한다.
