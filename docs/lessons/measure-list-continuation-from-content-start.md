# 목록의 이어지는 줄은 실제 본문 시작 열에서 센다

## What happened

- 클래스 전용 줄 앞에 빈 줄을 추가하자 상위 기호 줄에서 시작한 중첩 목록의 클래스가 들여쓴 코드 블록으로 읽혔다. 리뷰 wr-uo8y.j6e의 발견 1에 재현이 있다.

## Why

- 빈 자리표시 문단을 건너뛰면 첫 블록이 항목 기호와 같은 줄에서 시작한다. 이때 중첩마다 붙는 후속 줄 들여쓰기가 실제 본문 시작 열보다 커질 수 있다. 네 칸 이상 차이 나는 새 블록은 들여쓴 코드가 된다.

## Do this instead

- 목록 내부에 빈 줄이나 새 블록을 쓸 때 각 항목의 실제 본문 시작 열을 기준으로 후속 줄의 들여쓰기를 계산한다.
- 상위 기호와 같은 줄에서 시작한 중첩 목록도 다시 쓰고 파싱한다. 빈 줄 뒤 블록 종류, 문단 클래스, 목록의 촘촘함을 각각 확인한다.
