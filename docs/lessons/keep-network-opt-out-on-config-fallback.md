# 설정의 기본값으로 돌아갈 때도 명시적인 네트워크 비활성화를 보존한다

## What happened

- 갤러리가 `null`인 배포에서 다른 제품 설정 하나가 틀리면 전체 기본값을 썼다. 기본값의 갤러리가 다시 켜져 외부 요청을 시작할 수 있었다(wr-jfx7.qb3).

## Why

- 기능 활성화의 기본값과 서로 다른 설정 필드의 검증 실패가 하나의 처리 경로를 썼다. 설정을 끈 경우와 필드 검증에 실패한 경우를 함께 시험하는 단언이 없었다.

## Do this instead

- 구조를 읽을 수 있는 설정에서 명시적인 외부 기능 비활성화를 먼저 읽고, 나머지 필드가 기본값으로 돌아가는 경로에도 보존한다.
- 회귀 테스트에는 외부 기능 비활성화와 잘못된 별도 필드를 함께 넣는다. 기본값이 돌아오는 경우에도 비활성화가 그대로인지 확인한다.
