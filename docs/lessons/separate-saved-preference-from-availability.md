# 사용자 선택과 현재 가용성을 별도 상태로 유지한다

## What happened

- 마지막 컨테이너를 옮기면 빈 사이드바가 자동으로 숨었다. 저장 훅이 그 결과를 사용자가 선택한 숨김 값과 같은 키에 기록했다.
- 새로고침 후 **Reset View Locations**로 Explorer를 사이드바에 되돌려도, 복원한 숨김 값 때문에 사이드바는 숨은 채였다.

## Why

- 사용자 표시 설정과 컨테이너가 지금 그 위치에 있는지를 한 값으로 표현했다. 같은 세션에서 초기화하는 테스트는 저장과 복원 사이에 두 원인이 합쳐지는 경로를 실행하지 않았다.

## Do this instead

- 사용자 설정을 저장하고, 가용성은 현재 모델에서 첫 레이아웃 전에 계산한다. 두 상태로 실제 표시 여부를 정하고 실제 표시 여부가 바뀔 때 그리드와 컨텍스트 키를 갱신한다.
- 임시 조건으로 자동 숨김이 일어나는 기능은 조건을 만들고 새로고침한 뒤 조건을 제거한다. 파트가 다시 보이고, 사용자가 직접 숨긴 설정도 따로 유지되는지 확인한다.
