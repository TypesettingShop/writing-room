# API 입력과 저장된 값을 같은 검증기로 되살린다

## What happened

- 새로 지정한 웹뷰 탭 아이콘은 회전 수식자와 테마 색을 받았다. 별도 검증기를 쓰던 직렬화 경로에서 이 두 값이 빠졌다.

## Why

- API 입력과 저장된 데이터가 같은 표시 계약을 따르지만, 각 경로에서 허용 값과 정규화 규칙을 따로 정의했다.

## Do this instead

- 같은 형식의 구조와 허용 값은 공용 검증기에서 확인한다. 파일 소유권처럼 현재 환경에 의존하는 검사는 그 환경이 확인된 시점에 수행한다.
- 새로 추가한 필드를 API 입력, 저장, 다시 열기까지 왕복시켜 값과 권한 경계를 함께 확인한다.
