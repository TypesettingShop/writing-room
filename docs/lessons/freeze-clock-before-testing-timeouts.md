# 시간 의존 브라우저 테스트는 동작을 시작하기 전에 시계를 멈춘다

## 어떤 시험에서 드러났나

- 토스트 스펙에서 `page.clock.install()`만 실행하고 10초보다 오래 걸릴 수 있는 액션과 대기열 단언을 이어 갔다. 느린 환경에서는 제품의 자동 닫힘이 먼저 와서 검증하는 대기열 자체가 바뀐다 (wr-lnox.vha #7).

## 왜 그랬나

- `install()` 뒤에는 가짜 시계가 흐른다. `pauseAt()`으로 멈출 때부터 테스트가 진행한 시간만 지난다.

## Do this instead

- 탐색 전에 시계를 설치한다. 앱이 뜰 때까지 시간을 흐르게 두고, 시간 제한을 가진 동작을 만들기 전에 멈춘다.
- 경계값 직전과 직후를 `runFor()` 등으로 각각 확인한다. 시계를 멈췄을 때 프레임을 기다리는 입력이 있다면, 필요한 프레임만 진행하거나 키보드처럼 해당 프레임을 기다리지 않는 실제 입력을 사용한다.
