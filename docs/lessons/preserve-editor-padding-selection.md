# 편집기 여백을 처리할 때 드래그와 여러 번 클릭을 검증한다

## What happened

- Markdown 여백을 클릭할 때 원자 블록이 선택되는 문제를 고치면서 글 옆의 안쪽 여백까지 앱에서 처리했다. 그 자리에서 드래그를 시작하면 범위가 선택되지 않았다. 더블클릭 처리를 ProseMirror에 다시 넘긴 뒤에도 좌표가 블록 경계로 해석되면 단어가 선택되지 않았다.

## Why

- 같은 포인터 위치에서도 요소가 식별한 블록과 좌표가 가리키는 텍스트 위치가 다를 수 있다. 여백 이벤트를 취소하면 ProseMirror가 선택 제스처를 시작할 수 없고, 단어 선택에는 텍스트 블록 내부 위치가 필요하다.

## Do this instead

- 앱이 편집 위치를 직접 배치해야 하는 원자 블록과 ProseMirror가 글을 선택하는 안쪽 여백을 구분한다. 여백에서 글을 선택할 때는 좌표가 같은 줄의 텍스트 위치로 해석되는지 확인한다.
- Chromium에서 같은 여백을 대상으로 단일 클릭뿐 아니라 드래그와 더블클릭을 실행한다. 실제 DOM 범위와 선택된 단어를 검사한다.
