# 원격 리소스는 읽는 도중에 바이트 한도를 적용한다

## What happened

- 확장 매니페스트와 진입 파일에는 읽기 한도가 있었다. 원격 아이콘은 `response.blob()`으로 전체 응답을 메모리에 읽었다.

## Why

- 원격 서버는 `Content-Length` 없이 응답할 수 있다. 출처와 콘텐츠 형식 검사를 통과해도 응답 크기는 계속 커질 수 있다.

## Do this instead

- 원격 파일의 요청 정책과 읽기 처리는 공용 도우미에 두고 각 리소스의 바이트 한도를 전달한다. 읽은 바이트가 한도를 넘는 즉시 스트림을 취소한다.
- `Content-Length` 없이 한도를 넘기는 픽스처를 사용해 소비 경로의 회귀를 확인한다.
