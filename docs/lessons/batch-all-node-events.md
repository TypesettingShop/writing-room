# 트리를 떼었다 붙이는 동안에는 모든 노드 이벤트를 막고 끝에서 한 번 맞춘다

## What happened

- 그리드(wr-cla6.aym)의 GridView는 분할·축소·방향 전환 동안 batch로 한계 변경 이벤트만 막고 가시성 이벤트는 그대로 흘렸다.
- 리뷰(wr-hze8.cms) 1, 2번: 잠깐 비거나 숨겨진 자식만 남은 브랜치가 부모에서 숨겨졌다가 다시 보여 크기가 엉켰고, flipNode가 자식을 바꾼 뒤 가시성을 읽어 숨긴 열이 빈 띠로 나타났다.

## Why

- 재구성 도중의 트리는 불변식이 깨진 중간 상태다. 어떤 종류든 이벤트가 나가면 부모가 그 중간 상태에 반응한다.
- "이 이벤트는 정확성에 필요하니 살려 두자"는 예외가 바로 그 구멍이었다.

## Do this instead

- 노드를 떼었다 붙이는 변경은 하나의 batch 안에서 하고, batch 동안에는 한계·가시성·크기 이벤트를 하나도 내보내지 않는다.
- batch가 끝나면 아래에서 위로 한 번 상태(가시성, 한계)를 다시 맞추고 한 번 다시 배치한다.
- 재귀로 새 노드를 만들기 전에 옛 노드에서 읽을 값(비율, 가시성)을 먼저 모두 읽는다.
