# 스크롤하는 편집기 페이지에 그룹 크기를 전달한다

## What happened

- 분류 필드 페인의 페이지는 스크롤을 사용하지만 layout()에서 그룹의 크기를 전달하지 않아 페이지가 필드 전체 높이로 늘어났다. 편집기 컨테이너가 바깥 부분을 잘라 아래쪽 필드에 닿을 수 없었다.

## Do this instead

- 스크롤 영역을 가진 페인은 layout(dimension)에서 편집기 그룹이 준 폭과 높이를 스크롤 영역에 적용한다.
- 그룹보다 내용이 긴 브라우저 검증을 두고 페이지 높이가 편집기 높이에 맞는지 확인한다. 아래쪽 필드를 편집하거나 행을 끌 때 스크롤이 필요한 화면도 같은 페인에서 검증한다.
