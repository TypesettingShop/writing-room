# 레이아웃 설정이 가리키는 영역의 실제 폭을 검사한다

## What happened

- 마크다운 본문 폭을 80ch로 설정했을 때 안쪽 패딩과 경계선만큼 글줄이 좁았다. 폭의 기본값과 변경값의 비율만 검사한 브라우저 테스트는 통과했다.

## Why

- 편집기의 `max-width`는 `border-box`를 제한했다. 테스트에서 기대한 비율의 기준도 같은 바깥쪽 상자에서 읽었다.

## Do this instead

- 레이아웃 설정이 제한하는 영역을 정한다. 글줄 폭이라면 CSS에서 콘텐츠 영역에 설정값이 남도록 패딩과 경계선을 계산한다.
- 브라우저 테스트에서 실제 문단 폭을 재고, 같은 글꼴로 별도 요소에 설정한 `ch` 폭과 비교한다. 창을 줄였을 때의 상한과 여러 편집기의 설정 반영은 각각 검사한다.
