# 레이아웃 설정이 가리키는 영역의 실제 폭을 검사한다

## What happened

- 마크다운 본문 폭을 80ch로 설정했을 때 좌우 안쪽 여백(패딩)과 경계선만큼 글줄이 좁았다. 브라우저 테스트는 기본 폭과 변경한 폭의 비율만 확인했기 때문에 통과했다.

## Why

- 편집기의 `max-width`가 `border-box`의 폭을 제한했다. 테스트도 같은 바깥 상자의 폭을 읽어 비율을 계산했다.

## Do this instead

- 레이아웃 설정이 제한하는 영역을 먼저 정한다. 글줄 폭을 지정할 때는 CSS에서 콘텐츠 영역에 설정값이 남도록 안쪽 여백과 경계선의 폭을 계산에 넣는다.
- 브라우저 테스트에서는 실제 문단 폭을 재고, 같은 글꼴을 적용한 별도 요소의 `ch` 폭과 비교한다. 창이 좁을 때 본문이 표시 영역을 넘지 않는지, 여러 편집기에 설정이 반영되는지 각각 검사한다.
