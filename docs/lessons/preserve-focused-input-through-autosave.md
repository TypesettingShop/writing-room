# 자동 저장이 활성 입력의 원문을 덮어쓰지 않게 한다

## What happened

- 이름 끝에 공백을 입력하고 잠시 쉬면 자동 저장이 트림된 제목을 폼에 썼다. 다음 단어를 치자 앞 단어와 붙었다.

## Why

- 저장소가 정규화한 기준값과 입력란에 남겨야 할 초안을 한 값으로 다뤘다. 쓰기 응답과 직후의 다시 읽기가 활성 입력의 공백을 지웠다.

## Do this instead

- 저장할 값과 활성 입력의 초안을 따로 둔다. 저장 기준으로는 같은 값이라고 판단해도, 입력 중인 원문은 유지한다.
- 공백까지 친 상태에서 자동 저장한 뒤 다음 단어를 이어 쓰는 회귀 테스트에서 저장값과 화면의 값을 각각 확인한다.
