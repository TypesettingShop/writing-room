# API 속성 읽기에 문서 재검사를 연결하지 않는다

## What happened

- 확장 호환 코드가 visibleTextEditors를 읽을 때마다 그 목록에 없는 원고를 열기 이벤트로 다시 보냈다. 포커스 모드에서 에디터를 바꾸면 린터가 열려 있는 원고 전체를 반복 검사할 수 있었다.

## Why

- 같은 읽기 API를 초기화, 설정 반영과 포커스 이동이 함께 사용했다. 읽기만으로는 확장이 진단을 비우고 새 검사를 시작했는지 알 수 없었다.

## Do this instead

- 재검사는 진단 컬렉션을 비우는 동작처럼 실제로 갱신이 필요한 계기에 연결한다. 같은 틱의 중복 갱신을 합친다.
- 같은 속성을 여러 번 읽어도 이벤트가 생기지 않는지 검사한다. 이어서 갱신 동작을 실행해 필요한 문서가 한 번씩 다시 전달되는지 확인한다.
