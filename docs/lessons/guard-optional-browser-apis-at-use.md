# 선택 기능의 브라우저 API는 사용할 때 확인한다

## What happened

- 글자 수 모듈이 import 시점에 `Intl.Segmenter`를 만들었다. 이 API가 없는 브라우저에서는 글자 수 기능을 호출하기 전부터 편집기를 여는 경로가 깨졌다.

## Why

- 워크벤치가 기여 모듈을 시작 시 읽는다. 기능의 초기화가 모듈 평가에 붙으면 선택 기능의 브라우저 지원 범위가 워크벤치 시작 조건이 된다.

## Do this instead

- 선택 기능의 API는 처음 사용할 때 확인한다. API가 없는 환경에서는 기존 경로 또는 기능에 맞는 대체 동작을 실행한다.
- API를 지운 상태에서 모듈을 처음 읽고 대체 동작까지 한 테스트에서 확인한다.
