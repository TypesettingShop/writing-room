# 원문이 같은 편집도 블록과 커서 위치를 검사한다

## What happened

- 같은 구분선이 두 개 있는 문서에서, 원문을 같은 문자로 바꾸는 배치가 임시 커서 문단을 없앴다. 저장 문자열은 같았고 커서는 다음 텍스트 문단으로 옮겨 갔다.

## Why

- 원문 범위는 블록의 어떤 부분을 다시 썼는지 드러낸다. 저장 문자열 비교만으로는 블록 신원을 옮기는 매핑과 표시용 커서가 어디에 남았는지 알 수 없다.

## Do this instead

- 겉으로 같은 원문이 남는 외부 편집도 회귀 표본에 넣는다. 같은 범위의 문자를 그대로 다시 쓰는 경우와 중복된 블록 하나를 지우고 다른 위치에 같은 내용으로 넣는 경우를 각각 재현한다.
- 원문, 선택이 속한 블록이나 경계, 다음 입력이 쓰이는 위치를 별도로 비교한다. 표시용 커서만 움직인 경우와 저장 텍스트가 바뀐 경우의 이력 단계도 확인한다.
