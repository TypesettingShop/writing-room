# 페인 컨텍스트에서 그룹 상태의 상속을 유지한다

## What happened

- 새 WYSIWYG 페인이 자기 컨텍스트를 제목 메뉴에 노출하자 로딩 중과 읽기 실패 뒤에 원문 전환 버튼이 사라졌다. 오류 화면에 포커스를 두면 원문 전환 단축키도 듣지 않았다. wr-hbrm.fxd 1번에서 발견했다.

## Why

- 그룹이 현재 입력의 모드를 알고 있어도 페인 스코프의 명시적인 null이 부모 값을 가린다. 페인이 아직 뷰를 만들지 못한 상태에서도 제목 메뉴와 키바인딩은 페인 스코프를 읽는다.

## Do this instead

- 그룹이 소유한 입력 상태를 페인이 보충할 때는, 페인이 값을 제공할 수 없는 동안 로컬 키를 미정의로 둔다. 스코프를 처음 만들 때와 뷰를 해제할 때 모두 부모 값이 상속되는지 확인한다.
- 편집기를 여는 읽기를 보류해 제목 메뉴의 복구 동작이 보이는지 검사한다. 이어서 읽기를 실패시키고 오류 요소에서 단축키를 실행해 복구 경로가 작동하는지 확인한다.

Learned in: wr-hbrm.qx9
