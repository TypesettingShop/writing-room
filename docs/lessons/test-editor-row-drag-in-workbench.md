# 에디터 행의 드래그를 워크벤치 안에서 검증한다

## What happened

- Calendar 탭의 행 손잡이는 HTML 드래그 이벤트로 순서를 바꾸려 했다. 워크벤치에서 손잡이를 끌어도 행 순서는 그대로였다.

## Why

- 에디터 영역의 드롭 대상이 탭과 그룹에 대한 드래그를 처리한다. 이 경로에서 에디터 내부 행으로 보내려던 드롭 이벤트가 도달하지 않았다.

## Do this instead

- 에디터 안에서만 옮기는 행은 Field Template 편집기의 손잡이처럼 포인터 캡처를 쓰고 놓을 위치를 표시한다. 순서 버튼과 키보드 이동도 유지한다.
- 실제 워크벤치에서 손잡이를 눌러 다른 행으로 옮기는 브라우저 테스트로 화면의 순서와 저장된 ID 순서를 확인한다.
