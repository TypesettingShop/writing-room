# 편집기와 테스트는 실행 순서가 있는 플러그인 목록을 공유한다

## What happened

- Markdown 표의 테스트와 편집기 페인이 플러그인을 각각 설치했다. 테스트 목록에서 표 붙여넣기 플러그인이 빠졌고, 목록을 수정할 때 실제 편집기와 같은 순서를 보장할 수 없었다.

## Why

- 등록 순서가 붙여넣기 핸들러의 우선순위와 추가 트랜잭션의 실행 순서를 정한다. 예를 들어 짧은 표 행을 채우는 플러그인이 먼저 실행되어야 머리글이 원래 열에 남는다.

## Do this instead

- 순서가 동작을 결정하는 플러그인은 프로덕션 코드에서 순서가 정해진 목록 하나로 정의한다. 해당 경로를 검증하는 편집기 테스트도 그 목록으로 상태와 뷰를 구성한다.
